# Выкладка и обслуживание

## 1. Обрыв запросов при выкладке
- **Симптом:** всплеск ошибок 502/500 в момент выкладки.
- **Причина:** процесс завершается сразу по SIGTERM, не доделав запросы; балансировщик шлёт трафик на останавливаемый инстанс.
- **Как предотвратить:** graceful shutdown: перестать принимать новые, доделать текущие в пределах grace-периода; readiness-проба выключается до остановки.
- **Как проверить тестом:** SIGTERM во время долгого запроса → запрос завершается успешно, новые не принимаются.

## 2. Конфигурация отличается между окружениями
- **Симптом:** работает на стенде, падает в продакшене.
- **Причина:** отсутствующая переменная окружения, значение по умолчанию только для разработки.
- **Как предотвратить:** проверка обязательных переменных при старте (падение с понятной ошибкой); список в `.env.example`.
- **Как проверить тестом:** запуск без обязательной переменной → процесс не стартует, сообщение называет переменную.

## 3. Несовместимость версий во время постепенной выкладки
- **Симптом:** ошибки, пока работают старая и новая версии одновременно.
- **Причина:** изменение формата сообщений, кэша, API или схемы без совместимости.
- **Как предотвратить:** новая версия читает старый формат; формат меняется в две выкладки.
- **Как проверить тестом:** сообщение/запись старого формата обрабатывается новым кодом.

## 4. Режим обслуживания теряет работу
- **Симптом:** после обслуживания часть операций не выполнена.
- **Причина:** фоновые задачи и вебхуки во время остановки отбрасываются.
- **Как предотвратить:** очереди копят задачи; вебхуки получают ответ 503 с Retry-After, чтобы провайдер повторил.
- **Как проверить тестом:** вебхук в режиме обслуживания → 503 с Retry-After; задачи, поставленные во время остановки, выполнены после.
