# Платежи

## 1. Двойное списание
- **Симптом:** клиент оплатил один раз, деньги списаны дважды.
- **Причина:** повтор запроса к платёжке (ретрай, двойной клик) без ключа идемпотентности.
- **Как предотвратить:** ключ идемпотентности на каждую попытку оплаты, хранится с заказом; кнопка блокируется на время запроса.
- **Как проверить тестом:** два вызова оплаты с одним ключом → один платёж у фейкового провайдера, один статус «оплачен».

## 2. Повторный или поддельный вебхук
- **Симптом:** заказ оплачен без денег или статус меняется дважды.
- **Причина:** нет проверки подписи вебхука и обработка не идемпотентна по id события.
- **Как предотвратить:** проверка подписи; таблица обработанных id событий с уникальным индексом.
- **Как проверить тестом:** вебхук с неверной подписью → 401, статус не меняется; один и тот же вебхук дважды → одно изменение.

## 3. Вебхук раньше ответа или в другом порядке
- **Симптом:** «оплачен» перезаписан на «ожидает оплаты».
- **Причина:** события приходят не по порядку, обработчик просто присваивает статус.
- **Как предотвратить:** конечный автомат статусов: разрешены только переходы вперёд; запоздалые события игнорируются.
- **Как проверить тестом:** события «paid» затем «pending» → итоговый статус «paid».

## 4. Ошибки округления и валюты
- **Симптом:** сумма отличается на копейку, итог не сходится с суммой позиций.
- **Причина:** деньги во float; округление в разных местах; смешение валют.
- **Как предотвратить:** деньги в целых минимальных единицах или decimal с валютой; округление в одной точке по записанному правилу.
- **Как проверить тестом:** сумма 3 позиций по 0.10 = 0.30 ровно; скидка 33% от 1.00 по правилу округления; сложение разных валют → ошибка.

## 5. Возврат больше оплаты
- **Симптом:** суммарные возвраты превышают оплаченную сумму.
- **Причина:** параллельные возвраты без блокировки, проверка остатка вне транзакции.
- **Как предотвратить:** проверка и запись возврата в одной транзакции с условием «возвращено + сумма ≤ оплачено».
- **Как проверить тестом:** два параллельных возврата по 60% → один успешен, второй отклонён.
