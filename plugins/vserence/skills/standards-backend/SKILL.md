# Стандарт backend

## Принципы
1. Конфигурация из переменных окружения; в коде нет адресов, ключей и значений, отличающихся между окружениями.
2. Процессы не хранят состояние в памяти и на локальном диске между запросами: сессии, файлы, блокировки — во внешнем хранилище.
3. Повторный запрос с тем же ключом идемпотентности не создаёт дубль.
4. Явный таймаут на каждом внешнем вызове (HTTP, БД, очередь, файловое хранилище).
5. Повтор только для идемпотентных операций, с растущей задержкой и лимитом попыток.
6. Задачи дольше таймаута запроса уходят в очередь.
7. Процесс доделывает текущую работу при остановке для выкладки (обработка SIGTERM: перестать брать новое, закончить начатое, выйти).
8. Логи в stdout, структурированные (JSON или key=value), с id запроса в каждой строке.

## Как проверить
- [ ] Поиск в diff: нет литералов URL/хостов/ключей окружений; новые настройки читаются из env и описаны в `.env.example`.
- [ ] Нет глобальных изменяемых коллекций/кэшей в процессе, от которых зависит корректность; нет записи во временные локальные файлы, читаемые следующим запросом.
- [ ] Создающие эндпоинты и обработчики сообщений принимают ключ идемпотентности; есть тест «два одинаковых запроса → одна запись».
- [ ] У каждого нового внешнего вызова указан таймаут (значение видно в коде/конфиге).
- [ ] Повтор: только идемпотентная операция, задержка растёт (×2 или по формуле), лимит попыток задан числом.
- [ ] Операция, которая может длиться дольше таймаута запроса, поставлена в очередь; запрос возвращает id задачи.
- [ ] Есть обработчик сигнала остановки; тест или ручная проверка: задача, начатая до SIGTERM, завершается.
- [ ] Логи пишутся в stdout структурированно и содержат id запроса.

## Антипаттерны
- Повтор POST без ключа идемпотентности.
- Бесконечный повтор / повтор без задержки.
- Внешний вызов без таймаута «по умолчанию библиотеки».
- Загрузка/обработка тяжёлого файла внутри HTTP-запроса.
- `print`/`console.log` строкой без id запроса.

## Плохо / хорошо
```text
ПЛОХО:
  for i in 1..∞: try return http.post(url, body) catch continue
ХОРОШО:
  key = request.idempotencyKey
  for attempt in 1..5:
    try return http.post(url, body, timeout=5s, headers={Idempotency-Key: key})
    catch retryable: sleep(200ms * 2^attempt + jitter)
  fail "payment provider unavailable after 5 attempts"
```
