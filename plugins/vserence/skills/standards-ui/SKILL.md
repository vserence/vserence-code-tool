# Стандарт UI

Работает вместе со скиллом `frontend-design` (Anthropic): он задаёт визуальный стиль, этот чеклист — проверяемые требования.

## Принципы
1. Отступы и размеры по шкале с шагом 4 или 8 px.
2. Не более 3 уровней важности текста на экране (например: основной, вторичный, приглушённый).
3. Все состояния экрана: пусто, загрузка, ошибка, много данных.
4. Видимость статуса системы: каждое действие пользователя получает видимую реакцию (индикатор, сообщение, изменение).
5. Предотвращение ошибок пользователя: подтверждение необратимых действий, ограничения ввода, понятный текст ошибки рядом с полем.
6. Контраст не ниже 4.5:1 для обычного текста и 3:1 для крупного текста и элементов управления.
7. Всё доступно с клавиатуры: порядок фокуса логичный, фокус виден.
8. У каждого поля есть подпись (видимый label, связанный с полем).
9. Экран проверен на ширине 360 px.

## Как проверить
- [ ] Значения отступов/размеров в diff кратны 4 (или 8, если так в `conventions.md`).
- [ ] На экране ≤ 3 стилей важности текста.
- [ ] Для каждого нового экрана/компонента есть состояния empty, loading, error, overflow (длинные строки, 1000+ элементов) — визуальная проверка или тест.
- [ ] После каждого действия есть видимая реакция; необратимое действие требует подтверждения.
- [ ] Контраст пар цветов проверен инструментом (axe, Lighthouse или расчёт): ≥ 4.5:1 / ≥ 3:1.
- [ ] Проход с клавиатуры (Tab/Shift+Tab/Enter/Escape) по всем элементам; фокус виден.
- [ ] Автоматическая проверка доступности (axe или аналог) без нарушений уровня A/AA, если инструмент есть в проекте.
- [ ] Скриншот или e2e на ширине 360 px: нет горизонтальной прокрутки и обрезанного текста.

## Антипаттерны
- Placeholder вместо подписи поля.
- Только «счастливое» состояние экрана; пустой белый экран при ошибке.
- `outline: none` без замены видимым фокусом.
- Отступы 13px, 17px, 22px вперемешку.
- Кнопка без реакции во время запроса (двойная отправка).

## Плохо / хорошо
```text
ПЛОХО:
  <input placeholder="Email">  <button onClick=submit>OK</button>
ХОРОШО:
  <label for=email>Email</label> <input id=email type=email required aria-describedby=email-err>
  <span id=email-err role=alert>{error}</span>
  <button onClick=submit disabled={sending}>{sending ? "Отправляем…" : "Отправить"}</button>
```
